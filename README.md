# 🗂️ Employee Database App – Internship Task 7

A simple **Java console application** that connects to a MySQL database to manage employee records.  
It demonstrates JDBC integration, allowing operations such as adding, viewing, and managing employee details.

## ▶️ Run Instructions
1. Clone the repo: `git clone https://github.com/Lokesh-github07/Employee-Database-App.git`
2. Ensure MySQL is installed and running, and update connection details in the code if needed.
3. Compile: `javac src/EmployeeApp.java -cp lib/mysql-connector-j-9.3.0.jar`
4. Execute: `java -cp src:lib/mysql-connector-j-9.3.0.jar EmployeeApp`

## 📂 Structure
- `.vscode/` → workspace settings for development  
- `lib/mysql-connector-j-9.3.0.jar` → MySQL JDBC driver  
- `src/EmployeeApp.java` → main program handling employee database operations  
- `README.md` → project documentation
